# Printing repository

Before designing or printing scoreboard parts on the Bambu Lab X2D, read the
user's printing repository at `~/projects/printing` (`jubishop/printing`).
Its `memory/` holds X2D setup knowledge, workflow decisions, and past cases;
start with `memory/x2d-setup.md`, and search it with that repository's own
knowledge commands.

Push any generic printing lessons learned here back into that repository, such
as material, tolerance, orientation, or X2D behavior that applies beyond this
project. Follow its own instructions: print-job issues, dated `prints/`
records, and `memory/` updates only when durable guidance changes. Keep
lessons that apply only to the scoreboard in this repository.

**Why:** the user asked on 2026-10-24 that the printing repository's built-up
wisdom inform this project, and that this project's lessons improve it in
return.

**How to apply:** check the printing repository at the start of the
[enclosure phase](../docs/build-plan.md#6-enclosure) and before each print.
After each print, decide whether its lessons belong there, here, or both.
